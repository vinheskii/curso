# API de Cursos
API para gerenciamentos de professores e cursos

## Tecnologia
- JavaScript
- Node JS
- Mysql
- Express

## Endpoints
- `POST /professores` - Cria um professor
- `GET /professores` - Lista de professores
- `POST /cursos` - Cria um curso
- `GET /cursos` - Lista cursos
- `DELETE /cursos/id` - Deleta um curso por id
